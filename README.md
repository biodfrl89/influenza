# Influenza
Este repositorio fue creado para rediseñar la estrategia de análisis de influenza aviar. Se pretende hacer una reestructuración de el flujo de trabajo establecida por CENAPA-SENASICA, México.

## Flujo de trabajo general
Se establecen los pasos principales para el análisis bioinformatico de las lecturas obtenidas por secuenciación masiva de virus de influenza aviar (AIV)
